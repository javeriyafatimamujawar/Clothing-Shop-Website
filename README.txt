NAQAB Collection – Online Burqa & Abaya Shopping Website

A Stylish Online Shopping Platform for Modest Fashion

📌 About the Project

NAQAB Collection is a PHP and MySQL-based e-commerce website developed to provide customers with an easy and convenient online shopping experience for modest fashion products.

The website offers a collection of Burqas, Abayas, Hijabs, Naqabs and other accessories. It includes user authentication, shopping cart functionality, order placement and an admin dashboard for managing products and orders.

🚀 Features

👤 User Module

- User Registration and Login
- Browse Products
- Explore Different Product Categories
- View Product Details
- Add Products to Shopping Cart
- Place Orders
- UPI QR Code Payment Option
- Size Guide for Abayas

🔐 Admin Module

- Secure Admin Login
- Admin Dashboard
- Add, Update and Delete Products
- Manage Product Categories
- Manage Inventory and Stock
- View Customer Orders
- Sales and Revenue Reports
- Low Stock Management

📊 Dashboard Reports

- Total Orders
- Total Revenue
- Average Revenue
- Most Ordered Products
- Low Stock Products

⚙️ Installation & Setup

Follow these steps to run the project locally.

1. Download and install XAMPP.
2. Clone or download this repository.
3. Copy the project folder into the XAMPP "htdocs" directory.
4. Start Apache and MySQL from XAMPP Control Panel.
5. Open phpMyAdmin.
6. Create a new database.
7. Import the provided ".sql" database file.
8. Update the database connection settings in your PHP configuration file.
9. Open your browser and visit:

http://localhost/Naqab/
